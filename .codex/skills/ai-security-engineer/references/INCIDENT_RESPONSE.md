# Incident Response

1. **Detect** — record alert source, time, service and evidence.
2. **Triage** — determine credibility, affected identities/data and whether exposure is ongoing.
3. **Contain** — revoke tokens, rotate secrets, restrict vulnerable access or isolate affected systems without destroying evidence.
4. **Preserve evidence** — retain logs, request IDs, audit logs, commits, deployment history and timestamps.
5. **Eradicate** — remove compromised credentials, vulnerable code and malicious artifacts.
6. **Recover** — restore safely, increase monitoring and verify controls.
7. **Review** — document root cause, timeline, blast radius, control failure and preventive actions.
