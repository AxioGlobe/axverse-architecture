# AxioGlobe Security Scope

## PEER
Review authentication, organizations/tenants, project permissions, invitations, attachments, admin actions, enumeration and abuse controls.

## Manufacturer Catalogue
Protect manufacturer ownership, proprietary content, BIM assets, pricing and unpublished data. Test tenant isolation, authorization, exports and object ownership.

## GDL Validation Engine
Treat uploaded GSM/GDL and archives as untrusted. Review parser safety, path traversal, archive bombs, resource exhaustion, command execution and worker escape. Prefer isolated workers with CPU, memory, disk, network and execution-time limits.

## AxiForge
Protect manufacturer source data, generated BIM assets, prompts and proprietary templates. Test prompt injection, poisoned inputs, unsafe generated artifacts and cross-customer leakage.

## Archicad / Revit
Review code/update signing, credential storage, assembly/plugin loading, API transport, local file access and dependency risks.

## AI Agents
Require explicit identity, scoped permissions, tool allowlists, data boundaries, approval gates for destructive/sensitive actions, tool-call audit logs and prompt-injection resistance.

## Talent
Protect candidate data, assessments, CVs and recruiter/admin access.

## Admin Systems
Require MFA, least privilege, dedicated admin roles, audited actions and strong session protections.
