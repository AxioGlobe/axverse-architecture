# AI Security Engineer Tasks

## During active development
- Review newly introduced security-sensitive code.
- Check dependency and secret alerts.
- Review authentication/authorization changes.
- Review new AI tools and permissions.

## Three-session weekly cycle
### A — Code and API
Endpoints, auth/authz, tenant isolation, input validation and uploads.

### B — Infrastructure and supply chain
CI/CD, dependencies, secrets, cloud permissions and storage exposure.

### C — AI and threat modeling
Agent tools, retrieval sources, data isolation, prompt injection and business-logic abuse.

## Before production
Run the release security gate and document blockers, pre-production fixes, post-launch hardening and residual risk.
